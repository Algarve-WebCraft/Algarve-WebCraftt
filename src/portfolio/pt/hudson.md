challenge_text: O Hudson Designs foi criado como um conceito para designers freelancers que procuram uma forma simples e elegante de mostrar o seu trabalho online. O objetivo era demonstrar como um website limpo e minimalista pode colocar o portefólio de um designer em primeiro plano, sem distrações desnecessárias. O projeto centra-se numa tipografia cuidada, animações subtis e layouts cuidadosamente equilibrados para criar uma primeira impressão profissional.

approach_text: Em vez de depender de elementos visuais pesados ou interações complicadas, o foco esteve em criar um website que transmite elegância, confiança e facilidade de navegação. Cada página foi programada à mão de raiz, com especial atenção ao espaçamento, à tipografia e a interações fluidas que complementam o conteúdo do designer em vez de tentarem competir com ele.
approach_tick_1: Um portefólio minimalista criado para colocar o trabalho criativo em primeiro plano.
approach_tick_2: Galerias de projetos interativas que se expandem para apresentar trabalhos selecionados.
approach_tick_3: Um CV descarregável para potenciais clientes e empregadores.
approach_tick_4: Uma secção de testemunhos para reforçar a confiança e a credibilidade profissional.

testimonial_text: O website transmite uma sensação limpa, moderna e é incrivelmente fácil de navegar. Mostra o trabalho sem nunca se sobrepor a ele.
testimonial_span: Projeto Conceptual

built_text: Um website de portefólio refinado, criado para apresentar trabalho criativo de forma confiante e profissional. O layout equilibra espaços em branco generosos, uma tipografia elegante e animações subtis para criar uma experiência cuidada sem se tornar uma distração. Os visitantes podem explorar projetos em destaque, conhecer a experiência do designer, descarregar o CV e consultar testemunhos, tudo através de uma interface simples e intuitiva.

result_text: O Hudson Designs demonstra como um portefólio pode tornar-se parte da marca pessoal de um designer, em vez de ser simplesmente uma coleção de projetos. Cada secção foi criada para reforçar o profissionalismo, mantendo o foco firmemente no próprio trabalho.
result_tick_1: Um design limpo, inspirado no estilo editorial, que dá espaço para o trabalho criativo se destacar.
result_tick_2: Galerias de projetos interativas que incentivam os visitantes a explorar os trabalhos em destaque com mais detalhe.
result_tick_3: Um perfil profissional completo que reúne experiência, testemunhos e CV descarregável num só lugar.
result_tick_4: Animações subtis e interações cuidadas que criam uma experiência de navegação refinada e premium.
